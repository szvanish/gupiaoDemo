# 股票分析 Android App 设计文档

**日期：** 2026-04-28
**项目：** 多市场股票分析 Android 应用（含 Python 后端）

---

## 1. 项目概述

一款 Android 原生应用，允许用户通过股票名称或代码搜索 A股、港股、美股，从六个专业维度分析股票，并由大模型生成券商研报风格的分析报告和操作建议。同时每日推送全市场热点财经新闻与自选股专属新闻。

---

```

│                   Android App (Kotlin)               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐ │

│       └────────────┴─────────────┴───────────┘      │

└──────────────────────┬──────────────────────────────┘
                       │ HTTP/JSON
┌──────────────────────▼──────────────────────────────┐

│  ┌─────────────┐  ┌──────────────┐  ┌────────────┐  │
│  │  数据采集层  │  │  指标计算层   │  │  AI分析层  │  │
│  │ (A股/港股/  │  │ (技术面/基本  │  │(Claude API │  │
```

### 2.2 组件职责

| 组件 | 职责 |
|------|------|
| Android App | UI 展示、用户交互、本地缓存（Room） |
| FastAPI 后端 | 数据聚合、指标计算、AI 报告生成、缓存管理 |
| Redis | 实时行情缓存5分钟、财务数据缓存24小时、新闻缓存30分钟、AI报告缓存2小时 |
| SQLite | 新闻已读状态等轻量持久化 |

## 5. Android 页面结构

### 5.1 底部导航

底部固定 `BottomNavigationView`，4 个 Tab：自选股（首页）、搜索、新闻中心、设置。

### 5.2 各页面设计

#### 搜索页 (SearchFragment)
- 顶部搜索栏，实时联想匹配股票名称/代码
- 市场切换 Tab：A股 / 港股 / 美股
- 搜索结果列表：股票名称、代码、当前价、涨跌幅
- 点击跳转分析详情页

#### 自选股页 (WatchlistFragment)
- RecyclerView 卡片列表
- 每张卡片：股票名称、代码、实时价格、涨跌幅、迷你 K 线缩略图
- 长按删除，支持拖拽排序
- 点击进入分析详情页

#### 股票分析详情页 (StockDetailActivity)
- **行情区**：实时价格、涨跌幅、成交量、成交额
- **K线图区**：MPAndroidChart 渲染，支持日/周/月切换，支持均线叠加
- **六维评分雷达图**：技术面、基本面、估值面、情绪面、筹码与机构、宏观行业
- **指标面板**（可折叠 ExpandableListView）：展示各维度原始数据
- **AI 研报区**：ScrollView 展示完整研报正文
- **操作建议卡片**：结论评级 + 风险等级 + 核心逻辑摘要
- 右上角"加入自选"按钮

#### 新闻中心页 (NewsFragment)
- 顶部 TabLayout：全市场热点 / 自选股追踪
- 新闻卡片：标题、来源媒体、发布时间、相关股票 Chip 标签
- 下拉刷新，上拉加载更多
- 点击跳转内嵌 WebView 阅读全文

#### 设置页 (SettingsFragment)
- 大模型 API Key 输入与验证
- 数据刷新频率（15分钟 / 30分钟 / 1小时）
- 缓存大小显示与一键清理
- 关于页面

## 6. 股票分析六大维度

### 6.1 技术面
MA5/10/20/60、EMA12/26、MACD（DIF/DEA/柱）、RSI6/12/24、KDJ（K/D/J）、布林带（上轨/中轨/下轨）、成交量、量比、换手率、OBV、ATR 波动率、支撑位/压力位识别

### 6.2 基本面
PE（TTM/静态）、PB、PS、PCF、ROE、ROA、ROIC、营收同比/环比增速、净利润同比/环比增速、毛利率、净利率、资产负债率、流动比率、速动比率、自由现金流、每股净资产、每股收益（EPS）、股息率

### 6.3 估值面
与行业平均 PE/PB 横向对比、与自身历史 PE/PB 分位数纵向对比、PEG 合理性判断（PEG < 1 / 1-2 / >2）、简化 DCF 参考估值区间

### 6.4 市场情绪面
主力资金净流入/净流出（超大单、大单、中单、小单占比）、北向资金净买入（A股）、融资余额变化、融券余额变化、涨跌停情况、连板数、新闻热度评分（近24小时相关新闻数量加权）

### 6.5 筹码与机构
机构持仓占比及季报变化、前十大流通股东及变动、龙虎榜席位资金方向（A股）、股东总人数变化趋势（人数减少=筹码集中）、大股东近6个月增减持记录

### 6.6 宏观与行业
所属板块及近期板块涨跌表现、行业景气度评级、与沪深300/恒生指数/纳斯达克的近期相关系数、近期相关政策/监管新闻摘要

## 7. AI 研报生成

### 7.1 Prompt 结构
将六维分析的结构化数据拼装为 Prompt，指示大模型以"专业券商分析师"角色生成报告。

**报告章节：**
1. 摘要（100字内，核心结论）
2. 近期行情复盘
3. 基本面解读
4. 技术形态分析
5. 估值合理性评估
6. 市场情绪与资金动向
7. 风险提示（至少3条）
8. 操作建议（评级 + 目标价区间 + 买卖时机参考）

### 7.2 缓存策略
- 同一股票 AI 报告 Redis 缓存 **2小时**
- 股票实时行情缓存 **5分钟**
- 财务数据缓存 **24小时**
- 新闻列表缓存 **30分钟**

### 7.3 降级策略
- 大模型 API 超时（>30秒）或报错：返回规则模板生成的基础文字报告
- 数据源抓取失败：返回最近一次缓存数据，响应头标注数据时间戳

## 8. 后端 API 端点

```
GET  /stock/search?q={关键词}&market={A|HK|US}              # 股票搜索联想
GET  /stock/{code}/quote?market={A|HK|US}                   # 实时行情
GET  /stock/{code}/kline?market={A|HK|US}&period={day|week|month}  # K线数据
GET  /stock/{code}/analysis?market={A|HK|US}                # 六维分析原始数据
GET  /stock/{code}/report?market={A|HK|US}                  # AI 研报（带缓存）
GET  /news/hot?market={A|HK|US|all}&page={n}                # 热点新闻列表
GET  /news/stock/{code}?market={A|HK|US}&page={n}           # 个股相关新闻
GET  /health                                                 # 健康检查
```

> `code` 格式规范：A股为6位数字（如 `600036`），港股为5位数字（如 `00700`），美股为字母 Ticker（如 `AAPL`）。`market` 参数必填，避免同代码歧义。

## 9. 数据流

```
用户搜索/查看股票
       ↓
Android 发起请求 → FastAPI 检查 Redis 缓存
       ↓                    ↓
   缓存命中            缓存未命中
       ↓                    ↓
  直接返回          并行抓取多个数据源
                           ↓
                    计算六维指标数据
                           ↓
                    构建结构化 Prompt
                           ↓
                   调用 Claude API 生成报告
                           ↓
                   写入 Redis 缓存
                           ↓
                      返回 Android
```

## 10. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 数据源抓取失败 | 降级为缓存数据，标注数据时间 |
| 大模型 API 超时/报错 | 返回规则模板兜底报告 |
| 网络断开 | Android 端展示 Room 中上次缓存结果 |
| 股票代码不存在 | 返回 404，App 提示"未找到该股票" |
| Redis 不可用 | 降级为直接查询，跳过缓存 |

## 11. 本地开发启动

```bash
# 启动 Redis
docker run -d -p 6379:6379 redis

# 启动后端
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# Android 配置
# 在设置页填入后端地址：http://{本机局域网IP}:8000
# 填入 Claude API Key
```
